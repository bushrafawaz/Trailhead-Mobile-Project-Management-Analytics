# Trailhead Mobile — Project Management & Analytics

**A project-management practicum portfolio with ongoing analytics and automation extensions.**

**Status:** Practicum documentation completed (October–November 2026) · Portfolio extensions in progress.

## Overview

Trailhead Mobile is a **fictional case study** from the Mayerfeld Project Management Practicum. Team A5 planned the proposed launch of iOS and Android applications with offline maps for a Lisbon-based route-planning business. The work focused on project planning and governance — **not** on building or launching working mobile applications.

The simulated case covered a €180,000 total funding ceiling, a fixed marketing-campaign window, app-store review dependencies, offline map licensing, and a critical Android offline-download defect. The team documented realistic constraints, forecast assumptions, decisions awaiting authorization, and follow-up actions.

### Example planning findings (simulation)

- **Proposed cost baseline:** €156,067, including €5,000 proposed contingency. This was **not approved**.
- **Proposed management reserve:** €3,000, outside the cost baseline; total preliminary funding requirement €159,067. These are planning estimates, not actual project spend.
- **CR-01 recommendation:** investigate, correct, and regression-test the Android offline-map failure before release. The simulated sponsor decision remained **pending**.
- **Release plan:** the original joint-launch goal remained subject to readiness and explicit sponsor approval; **no revised launch date or completed software release was confirmed**.
